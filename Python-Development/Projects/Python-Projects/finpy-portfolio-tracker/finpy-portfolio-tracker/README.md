# FinPy Tracker - Asynchronous Financial Portfolio Dashboard

A powerful command-line interface (CLI) dashboard built with Python that tracks Stocks and Cryptocurrencies in real-time using asynchronous programming.

## 🚀 Features
- **Object-Oriented Architecture:** Implements Abstract Base Classes (ABC), inheritance, and encapsulation.
- **Asynchronous Data Fetching:** Uses `asyncio` and `aiohttp` to fetch live market prices in parallel.
- **Data Persistence:** Automatically saves and loads your portfolio data via local JSON storage.
- **Robust Error Handling:** Graceful fallbacks for network issues or corrupted files.

## 🛠️ Concepts Demonstrated
- **Basics:** File I/O, Error/Exception Handling, JSON Parsing, List Comprehensions.
- **OOPs:** Abstraction, Polymorphism, Data Encapsulation, `@property` Decorators.
- **Advanced:** Event Loops, Concurrent Tasks (`asyncio.gather`), Async HTTP Requests.
