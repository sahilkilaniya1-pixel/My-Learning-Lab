# 01 - RDBMS Concepts & Database Basics

## 1. Relational Database Management System (RDBMS) Kya Hai?
RDBMS ek aisa software system hai jo data ko Tables (Rows aur Columns) ke roop me organize, manage aur maintain karta hai.

## 2. Key Components
- **Table (Relation):** Data ka collection jo rows aur columns me hota hai.
- **Row (Tuple/Record):** Ek single entity ya item ki complete jankari.
- **Column (Attribute/Field):** Entity ki ek specific property (jaise Name, Age, Email).

## 3. ACID Properties (Database Integrity Rules)
- **Atomicity:** Dynamic transaction ya toh poori hoti hai ya bilkul nahi (All or Nothing).
- **Consistency:** Transaction ke pehle aur baad me database valid state me rehta hai.
- **Isolation:** Multiple transactions ek doosre ko distrub nahi karti.
- **Durability:** Save kiya gaya data system crash hone par bhi surakshit rehta hai.
